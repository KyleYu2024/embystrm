# Emby 神医助手社区版适配

这是基于 `sjtuross/StrmAssistant` 修改的 Emby 神医助手插件适配版。

## 适配版本

- Emby Server：`4.9.5.0`
- 插件版本：`2.0.0.31`
- 构建目标：Emby 4.9 SDK

## 安装

1. 下载或使用 `dist/StrmAssistantLite.dll`
2. 放入 Emby 配置目录的 `plugins` 文件夹
3. 重启 Emby Server
4. 在 Emby 插件页面确认插件已加载

## 说明

本仓库仅用于社区版神医插件在 Emby `4.9.5.0` 下的兼容适配。

原项目地址：[sjtuross/StrmAssistant](https://github.com/sjtuross/StrmAssistant)
